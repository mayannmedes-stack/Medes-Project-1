# May-Ann T. Medes — Personal Portfolio

A responsive personal portfolio website for May-Ann T. Medes, built with semantic HTML and CSS. The visual direction uses clear blue, purple accents, generous whitespace, and a friendly editorial layout.

## Structure

- `index.html` — main page
- `styles/main.css` — responsive visual system
- `assets/may-ann-profile.jpg` — supplied portrait
- `assets/favicon.svg` — monogram browser icon
- `manus-routes.json` — single-page route declaration
- `TODO.md` — delivery checklist

## Preview locally

```bash
python3 -m http.server 3000
```

Then open `http://localhost:3000`.

## Before publishing

Replace `mayann.medes@example.com` in `index.html` with a preferred contact address or social link, then commit and publish the project through GitHub Pages.

## GitHub Pages handoff

For the class submission, create a repository named after the project, push the `main` branch, and enable **Settings → Pages → Deploy from a branch → main / root**. The resulting GitHub Pages address can be submitted together with the repository URL.
