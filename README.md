# May-Ann T. Medes — Personal Portfolio

A responsive personal portfolio website for May-Ann T. Medes, built with semantic HTML and CSS.

## Structure

- `index.html` — main page
- `styles/main.css` — responsive visual system
- `assets/may-ann-profile.jpg` — supplied portrait
- `manus-routes.json` — single-page route declaration

## Preview locally

```bash
python3 -m http.server 3000
```

Then open `http://localhost:3000`.

## Before publishing

Replace `mayann.medes@example.com` in `index.html` with a preferred contact address or social link, then commit and publish the project through GitHub Pages.
